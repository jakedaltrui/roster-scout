| Boundary | Description |
|----------|-------------|

| Draft snapshot → published reads | Only fully traced, tenant-owned canonical facts may cross into ready/partial visibility. |
| NCAA ID → existing Player | An upstream reused/corrupted ID can collide with stored material identity. |
