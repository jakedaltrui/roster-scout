## Phase Goal

**As a** Roster Scout operator, **I want to** publish existing NCAA D1/D2/D3 results through a durable job into an immutable, provenance-rich canonical snapshot, **so that** every downstream report can rely on one auditable source of truth without breaking today's workbook workflow.

<objective>
Create the privacy-conscious event and reporting foundation for usage and download metrics without adding authentication to Phase 1.

Purpose: Give operators durable, deduplicated download counts now and a stable column/service contract for exact unique authenticated users when Phase 2 supplies and relationally binds account IDs.
Output: Revision 0012, usage service, operator CLI, and PostgreSQL tests.
</objective>
