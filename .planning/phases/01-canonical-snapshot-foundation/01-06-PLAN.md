<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Redis/Celery → worker | Messages are at-least-once and may arrive simultaneously. |
| Worker → Browserless | Duplicate execution can exhaust scarce external sessions. |
| Worker → PostgreSQL | Only one claimant may advance attempts and persist results. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06-01 | Denial of Service | duplicate task delivery | mitigate | PostgreSQL whole-attempt advisory claim plus bounded backoff. |
| T-01-06-02 | Tampering | attempt_count/job state | mitigate | Increment only after exclusive claim and verify with independent sessions. |
| T-01-06-03 | Repudiation | duplicate execution | mitigate | Durable job/snapshot state and deterministic concurrency assertions. |
| T-01-06-04 | Information Disclosure | task payload/failures | mitigate | Opaque UUID payload and sanitized retry outcomes. |
</threat_model>
