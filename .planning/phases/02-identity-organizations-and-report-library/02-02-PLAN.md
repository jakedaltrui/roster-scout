## Trust Boundaries

| Boundary | Description |
|---|---|
| WorkOS SDK → adapter | External availability/errors enter the application. |
| Session → authorization service | Every caller must re-prove local active membership before receiving organization context. |
| Provider session → local session | Refresh/logout outcomes must not revive revoked local state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-02-01 | Elevation | SSO/JIT/domain claims | mitigate | Ignore provider membership/domain; local active membership only; negative emulator/two-org tests. |
| T-02-02-02 | Elevation | membership context | mitigate | Reload account/membership server-side; ignore provider/request organization and role claims. |
| T-02-02-03 | Spoofing | session refresh | mitigate | Row lock/CAS rotated sealed state; local expiry/revocation authoritative. |
| T-02-02-04 | Denial | provider outage | mitigate | Preserve session on retryable failures; terminal revoke only on invalid/revoked provider result. |
| T-02-02-05 | Information disclosure | SDK/logging | mitigate | Fixed categories; no callback/provider exception, token, assertion, or sealed-session material. |
| T-02-02-SC | Tampering | dependencies | mitigate | Install only the exact `workos`/`Flask-WTF` pins approved by the Package Legitimacy Audit; emulator remains optional and official. |
