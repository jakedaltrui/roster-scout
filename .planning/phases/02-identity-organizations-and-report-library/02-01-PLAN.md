## Trust Boundaries

| Boundary | Description |
|---|---|
| Provider exchange result → identity/account services | Untrusted provider data crosses into canonical local account linkage. |
| Auth transaction state → provider exchange | A one-time local state capability authorizes exactly one exchange attempt. |
| Opaque verifier → PostgreSQL session | A bearer verifier selects sensitive server-side state and must never be stored raw. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-01-01 | Spoofing | auth transaction service | mitigate | One-time state digest, fixed expiry, consume-before-exchange, and verified identity result. |
| T-02-01-02 | Spoofing | session creation | mitigate | Rotate the pre-auth verifier, use a ≥128-bit opaque verifier, and persist only its SHA-256 digest; Plan 02-13 owns cookie emission. |
| T-02-01-03 | Elevation | account linking | mitigate | Unique issuer/subject and provider-supported verified linking; reject unverified/conflicting email. |
| T-02-01-04 | Information disclosure | auth logs/errors | mitigate | Allowlisted fixed categories; tests prohibit codes, state, raw email, tokens, sealed state, and exception text. |
| T-02-01-SC | Tampering | dependencies | accept | No package install occurs in this plan; Plan 02-02 owns the audited exact pins. |
</threat_model>
