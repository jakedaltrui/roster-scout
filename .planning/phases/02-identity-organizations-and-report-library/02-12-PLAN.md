## Trust Boundaries

| Boundary | Description |
|---|---|
| Flask request → authorization backend | Every route/method must apply the same session/membership gate. |
| Browser form/JSON → unsafe route | CSRF can mutate logout, membership, report, refresh, retry, or acknowledgement state. |
| Tracked config/docs → deployed secrets | Misconfiguration can leak credentials or imply false production readiness. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-02-12-01 | Elevation | route gate | mitigate | Short public allowlist; default protected hook; explicit complete route matrix. |
| T-02-12-02 | Tampering | unsafe methods | mitigate | Global Flask-WTF CSRF for forms and JSON; no GET mutation. |
| T-02-12-03 | Spoofing | logout/callback composition | mitigate | Consume state and rotate on callback; revoke local session before provider logout. |
| T-02-12-04 | Information disclosure | config/errors | mitigate | Secret scans, env-name-only tracked config, fixed sanitized messages/logs. |
| T-02-12-05 | Denial | provider/config absence | mitigate | Fake-backed deterministic execution; fail production startup closed; code completion independent of live service. |
| T-02-12-SC | Tampering | dependencies | accept | No new package install; consumes exact audited pins from Plan 02-02. |
</threat_model>
