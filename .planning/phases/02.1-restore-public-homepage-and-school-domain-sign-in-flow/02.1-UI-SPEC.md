# Phase 02.1 — UI Design Contract

## Design System

The pre-Phase-2 `templates/index.html` at commit `fa18b73e` is the visual baseline. Preserve its DM Sans typography, cream/black/green palette, dog mark, exact-team combobox, workbook preview, motion, light/dark themes, and responsive behavior. Use existing HTML, CSS, and vanilla JavaScript; add no component library.

## Homepage Contract

- `/` renders the homepage for signed-out and signed-in visitors.
- Keep the original hero, selector card, workbook preview, how-it-works, FAQ, final CTA, and footer hierarchy.
- Add one quiet header action: **Sign in** when signed out, **Saved reports** when signed in.
- Do not add a dashboard sidebar, organization picker, pricing card, or account-management panel to the homepage.
- Change only copy that is now inaccurate: generation requires a verified school email; browsing does not.

## Authentication Handoff

- Trigger only after a valid exact team is selected and generation is attempted.
- Keep the selected team visible in the handoff copy when safely available from the bounded resume record.
- Primary CTA: **Continue with school email**.
- Supporting copy: passwordless, no password to create, and the verified `.edu` address connects the user to the school's shared reports.
- Do not render a local email/password form. Hosted identity remains the credential surface.
- Returning users with a valid session never see the handoff.

## Portal Contract

- The portal is a secondary, task-focused surface—not a replacement homepage.
- Primary navigation contains only **New report**, **Saved reports**, and a compact account menu.
- **New report** returns to the homepage selector rather than maintaining a second competing team-selection experience.
- The report library uses one simple list/table with opponent, latest snapshot, state, freshness, and one primary action.
- Report detail emphasizes current saved snapshot, refresh, history, and download.
- Membership and invitation management are absent from primary navigation. Existing authorized direct routes remain available for support/future administration.
- Avoid analytics widgets, onboarding checklists, billing prompts, plan badges, and organization dashboards.

## Interaction and Accessibility

- The resume record expires after 15 minutes, contains no email or account identifier, and is removed after successful restoration or definitive failure.
- Sign-in/resume announcements use existing live regions and never produce duplicate submissions.
- Preserve keyboard combobox behavior, visible focus, 44px touch targets, reduced motion, and 320px responsive support.
- If session storage is unavailable, return to the homepage after sign-in with a clear prompt to select the team again; do not fail authentication.
