- The portal remains secondary and task-focused: create a report, review saved snapshots, refresh, and download.

## Interaction audit

The audit covered every shared interactive primitive and every customer-facing page that inherits the product shell:

- Navigation: brand, current-page action, account menu, outside-click/Escape dismissal, and theme toggle.
- Actions: primary, secondary, quiet, danger, disabled, pressed, pending, and keyboard-focus states.
- Forms: text inputs, selects, division controls, team results, validation, pending submission, and status feedback.
- Content: report tables, mobile cards, snapshot panels, status chips, banners, empty states, and live refresh updates.
- Overlays: account dropdowns, confirmation dialogs, backdrop treatment, focus return, and dismissal.
- Page motion: header entrance, headline reveal, and one content-surface entrance using the homepage timing and easing tokens.

The one-off demo entrance was removed so it inherits the shared page rhythm. The dashboard empty state now uses an understated workbook preview instead of the dog logo and provides one clear next action.
