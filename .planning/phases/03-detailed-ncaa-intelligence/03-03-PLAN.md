<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI IDs/output path → browser capture | Operator arguments could redirect source access or overwrite arbitrary files. |
| Browserless/NCAA response → committed fixture | HTML may contain secrets, scripts, challenge content, or misleading controls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Information Disclosure | fixture sanitizer | mitigate | Allowlist minimum tags/attributes, remove scripts/cookies/query credentials, scan outputs for secret-shaped values, and commit only sanitized evidence. |
| T-03-03-02 | Tampering | split identifier discovery | mitigate | Bind identifier to season/type/label/header/player-link contracts and reject stale or mismatched responses. |
| T-03-03-03 | Denial of Service | Browserless capture | mitigate | Existing shared slot plus validated navigation count, timeout, and output-size caps. |
| T-03-03-04 | Elevation of Privilege | output path / source host | mitigate | Confine writes to fixture roots and construct only fixed NCAA paths from numeric IDs. |
| T-03-03-SC | Tampering | package supply chain | accept | No package install; the tool reuses existing pinned Browserless/parser code. |
</threat_model>
