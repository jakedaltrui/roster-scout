## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NCAA count values → metric engine | Untrusted strings and nullable counts become canonical Decimal results. |
| Draft snapshot facts → PostgreSQL | Tenant-owned metric rows become immutable downstream truth. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01-01 | Tampering | `canonical.py` / `metrics.py` | mitigate | Strict Decimal/integer parsing, nonnegative checks, incompatible-input states, and golden formula tests reject poisoned counts. |
| T-03-01-02 | Information Disclosure | `MetricValue` ownership | mitigate | Composite organization/snapshot/source references and negative PostgreSQL tests prevent cross-tenant substitution. |
| T-03-01-03 | Repudiation | metric methodology | mitigate | Persist definition version, exact inputs/sample, reason code, and constant-set version with every value. |
| T-03-01-04 | Tampering | NCAA constant sets | mitigate | Use only append-only verified exact-season/division sets with checksummed provenance and composite definition linkage; seed none by default. |
| T-03-01-SC | Tampering | package supply chain | accept | No package install occurs in this plan; existing pinned dependencies remain unchanged. |
</threat_model>
