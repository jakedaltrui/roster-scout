<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Schedule/conference HTML → Game identity | Contest state, opponent IDs, and conference IDs are untrusted source data. |
| Games → computed scope membership | Selection errors could silently change recent/conference results. |
| Scope membership → published snapshot | Membership must not cross snapshots or mutate after publication. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06-01 | Spoofing | conference classification | mitigate | Require same-season source-backed team/opponent conference IDs; unknown on any mismatch. |
| T-03-06-02 | Tampering | last-10 selector | mitigate | Pure deterministic ordering, exact normalized membership, edge-case fixtures, and no downstream recomputation. |
| T-03-06-03 | Information Disclosure | scope membership ownership | mitigate | Composite tenant/snapshot/game/scope foreign keys plus negative substitution tests. |
| T-03-06-04 | Repudiation | partial scope | mitigate | Persist exact game IDs/dates/count/range, status/reason, evidence checksum, and source collection time. |
| T-03-06-SC | Tampering | package supply chain | accept | No package installation; existing source/runtime is reused. |
</threat_model>
