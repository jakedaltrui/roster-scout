| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-05-01 | Spoofing | career team identity | mitigate | Accept source link or exact season-specific lookup only; ambiguous text stays partial/unavailable. |
| T-03-05-02 | Tampering | two-way/transfer linkage | mitigate | Stable NCAA Player ID is authoritative; facts remain typed and team-season rows remain separate. |
| T-03-05-03 | Information Disclosure | snapshot drill query | mitigate | Derive tenant from authorized snapshot membership and use composite organization/snapshot/player filters. |
| T-03-05-04 | Denial of Service | player-page fan-out | mitigate | One fetch per stable player/type, shared Browserless slot, hard request/time budgets, and durable backoff/cache authority. |
| T-03-05-05 | Repudiation | aggregate completeness | mitigate | Persist included/excluded career row IDs and exact reasons with definition version and source evidence. |
| T-03-05-SC | Tampering | package supply chain | accept | No new package or scraper runtime is introduced. |
</threat_model>
