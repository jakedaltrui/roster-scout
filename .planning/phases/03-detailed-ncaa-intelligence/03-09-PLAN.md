| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-09-01 | Elevation of Privilege | player detail route | mitigate | Derive organization from membership context and require composite report/snapshot/player ownership; foreign and absent IDs share one audited 404. |
| T-03-09-02 | Information Disclosure | JSON projection | mitigate | Fixed field/view allowlist, published-snapshot joins, no raw HTML/customer identity, and cross-organization response tests. |
| T-03-09-03 | Denial of Service | detail query | mitigate | Bounded view vocabulary, indexed ownership keys, fixed projection, and no live NCAA access. |
| T-03-09-04 | Tampering | historical snapshot response | mitigate | Read-only service plus PostgreSQL published-child immutability and successor/predecessor regression. |
| T-03-09-SC | Tampering | package supply chain | accept | No package installation; existing Flask/SQLAlchemy authorization patterns are reused. |
</threat_model>
